What this page is: a read-only viewer. It never asks for, generates, imports, stores, or transmits a private key or recovery phrase -- there is nothing here that could hold one. It only ever looks up public balances for an address you paste in.

What it talks to: the public RPC endpoint of whichever network you're viewing (to read a balance), CoinGecko's free public API (for prices), and Polymarket's public Gamma API (for the trending-markets card). No account, no analytics, no server of ours in between -- your browser talks to those three directly.

Where your data lives: saved addresses, tracked tokens, your currency choice, and your watchlist stars are stored only in this browser's local storage. Clearing your browser data clears them. Nothing is synced anywhere.

Companion to the Token Exchange browser extension -- a separate, self-custody wallet that does hold keys (encrypted, on your device only) and can send/swap. This page is intentionally unable to do either.
